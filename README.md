# html-and-css-projects---admin-page
Creating an admin webpage using HTML and CSS that is responsive on computers and tablets, but not yet responsive on mobile phones.

I built an admin page project using HTML and CSS. I kept the HTML and CSS files separate to make the code easier to understand. I also utilized semantic HTML and ensured the website is responsive for laptop and tablet screen sizes.
